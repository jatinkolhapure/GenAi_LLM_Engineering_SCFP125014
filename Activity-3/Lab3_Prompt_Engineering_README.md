\## Objective



To understand and implement prompt engineering techniques using a Large Language Model (LLM) through the Groq API.



\## Technologies Used



\- Python

\- Jupyter Notebook

\- Groq API

\- `python-dotenv`

\- JSON



\## Exercises Completed



\### Exercise 1: Doctor Summary Generator

Generates a structured summary from patient notes with symptoms, diagnosis, and recommendations.



\### Exercise 2: Review Classifier

Classifies customer reviews into Positive, Negative, or Mixed categories.



\### Exercise 3: Resume Field Extractor

Extracts requested fields from resume text and returns the results in JSON format.



\### Exercise 4: Customer Support Reply Generator

Generates a polite customer support response within a specified word limit.



\### Exercise 5: Multi-language Translator

Translates a sentence into a target language while following the requested level of formality.



\### Exercise 6: Iterative Content Refiner

Improves a draft through multiple rounds of refinement based on a specified issue.



\## How to Run



1\. Install Python and Jupyter Notebook.

2\. Install the required dependencies:



&#x20;  ```bash

&#x20;  pip install groq python-dotenv

&#x20;  ```



3\. Create a `.env` file in the project root and add your Groq API key:



&#x20;  ```text

&#x20;  GROQ\_API\_KEY=your\_groq\_api\_key

&#x20;  ```



4\. Open `Lab3\_Prompt\_Engineering.ipynb` in Jupyter Notebook.

5\. Run the notebook cells sequentially.



\## Security Note



Do not upload the `.env` file or expose your Groq API key in the notebook, source code, or GitHub repository.
